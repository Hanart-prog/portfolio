# Hanat Sharif — Portfolio

Personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and GSAP.

```sh
npm install
npm run dev
```

Requires Node 22.12+. Site content lives in `src/data/portfolio` and `src/i18n.ts`.

Design and code adapted from [nayetdet.dev](https://nayetdet.dev) by João Pedro Moreira.
